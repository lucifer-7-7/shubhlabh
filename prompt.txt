### Design System & Constraints (Inspired by Apple's premium layout and modern lookbooks)
1. Color Palette: Pure White (#FFFFFF) for main canvas backgrounds, Apple Light Gray (#F5F5F7) for secondary boxes and alternate page sections, Obsidian Carbon (#1D1D1F) for body copy and dark outlines, and a striking Product Red (#E11D48) as the single pop accent color.
2. Layout Style: Asymmetrical editorial layout. Segment content using generous whitespace offsets (140px section paddings) and thin, soft boundary borders (1px solid rgba(0, 0, 0, 0.08)) rather than heavy solid black lines.
3. Cornering & Rounding (Apple iOS Reference): Apply Apple iOS standard rounded rectangles (12px border-radius) for all cards, forms, mockup boxes, and modals. Apply 8px border-radius for buttons, segmented tabs, and text input boxes.
4. Input Fields: Form input fields must use a soft background fill (#F5F5F7) with rounded corners (8px), subtle padding, and transition border borders (from transparent to dark charcoal) upon focus. No raw under-lining boxes.
5. Typography Reset: Enforce `text-decoration: none` on all link `<a>` tags globally to prevent default browser underlines on menus and buttons.
6. Iconography: STRICTLY NO emojis. Use clean, professional, lightweight inline vector SVGs for all visual icons (such as location indicators, checklists, and network maps).
7. Grid Alignments: Ensure all vertical lists (About stats, Product Categories, Why Us, Careers) align perfectly. Use a matching left-aligned column track of 80px width to host list index numbers (e.g. [01], [02] //) and text-align the arrow indicators (→) or buttons to the right-most column track to establish pixel-perfect grid borders.
8. Mission List Bullets: Bullet numbers (e.g., '02 /') must never wrap the slash character to a second line. Enforce `white-space: nowrap` and `flex-shrink: 0` on bullet tags.
9. Mobile Responsiveness & Spacing:
   - Decrease typography sizing on mobile viewports (screen widths <= 768px): h1 (2.2rem), h2 (1.6rem), h3 (1.1rem), body text (0.84rem) and annotations (0.58rem) to preserve clean high-density layout.
   - Intensify negative spacing on mobile: Apply tight -0.05em letter-spacing on h1, -0.04em on h2/h3, and -0.02em on paragraphs. Include slight vertical heading overlaps (e.g., script text margin-top: -6px) to build visual connections.
   - Tighten section heights on mobile devices (padding: 75px 0) to maintain a neat page flow.
   - Floating Hero annotations should stack dynamically underneath the text block and scale down (width: 290px on phones) to prevent horizontal scroll bars.
   - Display vertical grid listings cleanly on mobile using simplified columns on <= 600px.
10. Header Width: Align the header navigation bar container width exactly to the site content grid container width (max-width: 1100px) so left/right boundaries match perfectly. Apply a saturated blur backdrop-filter (20px) to the header.
11. Preloader Loading Screen:

    - Shuffled greetings order: "नमस्ते" must ALWAYS display first. Shuffled other languages randomly using a Fisher-Yates method for subsequent rotations.
    - Animate the text in an infinite fade loop using GSAP opacity transitions (no 3D flips/rotations): hold current greeting visible (0.75s), fade-out current greeting (0.35s), swap text content *invisibly* at zero opacity, then fade-in the new word (0.35s).
